# Construction Management Platform

منصة مستقلة لإدارة المقاولات والإنشاءات، عربية أولاً وقابلة للتوسع.

## الرؤية
بناء منتج SaaS لإدارة المشاريع والعقود وجداول الكميات وقياسات الأعمال والمستخلصات والمراجعات والاعتمادات، مع توسع تدريجي إلى منظومة ERP متخصصة في قطاع الإنشاءات.

## قرارات معتمدة
- الملكية الأولية شخصية للمؤسس.
- المشروع مستقل عن أي شركة مقاولات قائمة.
- هوية تجارية جديدة مستقلة؛ الاسم لم يعتمد بعد.
- المنتج قابل لجذب استثمار مستقبلاً.

## مبادئ أساسية
- الحسابات الهندسية والمالية حتمية وقابلة للاختبار؛ لا يستخدم AI لحساب المستحقات النهائية.
- الكميات المسجلة والمقاسة والمدققة والمعتمدة والمصروفة مراحل منفصلة.
- كل تغيير بعد الاعتماد يجب أن يكون موثقاً.
- عزل بيانات المؤسسات عبر PostgreSQL Row Level Security.
- لا ترفع بيانات عملاء أو شركات حقيقية دون تصريح صريح.
- لا تضع مفاتيح Supabase السرية في المتصفح أو GitHub.

## التقنية المقترحة
- Next.js + TypeScript للويب.
- Supabase / PostgreSQL للمصادقة والبيانات والملفات.
- Figma لتصميم الواجهات.

## الحالة
- مستودع GitHub موجود.
- تصميم أولي للوحة التحكم موجود في Figma.
- مشروع Supabase لم ينشأ بعد.
- لا يوجد تطبيق منشور أو قاعدة بيانات إنتاجية.

راجع `docs/PRODUCT_SCOPE.md` و`docs/DATA_MODEL.md` قبل توسيع النطاق.
